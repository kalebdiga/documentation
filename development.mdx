---
title: "Local docs preview"
description: "Preview the BlitzBoard documentation site locally with Mintlify."
---

<Info>
  **Prerequisites**
  - Node.js 19+
  - This repository (with `docs.json` at the root)
</Info>

<Steps>
  <Step title="Install the Mintlify CLI">
    ```bash
    npm i -g mint
    ```
  </Step>
  <Step title="Start the preview">
    From the documentation directory:

    ```bash
    mint dev
    ```

    Open `http://localhost:3000`.
  </Step>
</Steps>

Use a custom port if needed:

```bash
mint dev --port 3333
```

Validate links:

```bash
mint broken-links
```
